# 噜噜时间追踪 (Lulu Time Tracker)

一个优雅的玻璃拟态桌面时间追踪与日历规划挂件，基于 Electron 构建。

## 功能特性

### ⏱ 智能计时
- **手动控制**：开始 / 暂停 / 继续 / 结束，完全掌控计时节奏
- **四分类**：支持 📚 学习、💼 工作、🎮 娱乐、🌱 生活四种任务类型
- **跨会话恢复**：关闭软件后重新打开，计时自动接续
- **可编辑时间**：结束计时时可手动修正起止时间

### 🐾 噜噜桌面精灵
- 根据当前任务类型自动切换表情（待机 / 学习中 / 元气满满 / 困困中 / 摸鱼中）
- 定时冒泡随机鼓励语
- 点击互动、右键菜单控制显示
- 可拖拽摆放到桌面任意位置

### 📅 日历与计划
- 月度日历视图，每日活动点标记
- 日程规划：添加时间段任务，支持勾选完成
- 选中日期显示当日时间分布和活动时间线

### 📝 笔记与管理
- **灵感记录**：快速捕捉想法，支持收藏
- **备忘清单**：待办事项管理，支持完成/删除
- **每日复盘**：写日记式总结，自动展示当日时间分布
- **数据分析**：按周/月/自定义范围查看时间统计和 Top 活动

### 🎨 视觉体验
- 毛玻璃拟态 UI（backdrop-filter）
- 窗口大小与 UI 自动同步缩放
- 支持折叠/展开双形态
- 无边框透明窗口，可拖拽

├── pet-preload.js          # 精灵窗口预加载桥接

## 快速开始

### 环境要求

- [Node.js](https://nodejs.org/) >= 18
- Windows 10/11

### 开发运行

```bash
# 安装依赖
npm install

# 启动应用
npm start

# 或直接运行
start.bat
```

### 构建安装包

由于 electron-builder 需要额外安装，当前采用手动构建方式：

1. 确保 `node_modules/electron/dist/` 存在
2. 运行 `create-shortcut.ps1` 生成桌面快捷方式
3. `build/` 目录下为便携版（可直接运行 `噜噜时间追踪.exe`）

## 使用说明

### 计时流程

```
[▶ 开始计时] → 选择任务类型 → 计时开始
    ├─ [⏸ 暂停] → 计时暂停
    │   └─ [▶ 继续] → 恢复计时
    └─ [⏹ 结束] → 填写活动详情 → 保存记录
```

### 窗口控制

| 按钮 | 功能 |
|------|------|
| 📌 | 切换窗口置顶 |
| ▼/▲ | 折叠/展开记录面板 |
| A⁻ A A⁺ | 缩放调节（0.5x ~ 3.0x） |
| 📅 | 打开日历与计划面板 |
| ❓ | 打开笔记与分析面板 |
| — | 最小化到任务栏 |
| □ | 最大化/还原 |
| ✕ | 关闭 |

### 噜噜精灵操作

- **左键点击**：互动反应 + 随机回复
- **右键点击**：显示菜单（切换置顶 / 隐藏）
- **拖拽**：按住任意位置拖动到想要的位置

## 数据存储

所有数据保存在 `data.json` 中，包括：

- `logs`：时间追踪记录
- `schedules`：每日计划
- `ideas`：灵感记录
- `memos`：备忘清单
- `reflections`：每日复盘
- `timerState`：计时器状态

建议定期备份此文件。
